Key Architectural Principles

1. Zero Data Leakage

All imputers, encoders, feature engineering operations, and class balance transforms are fitted exclusively within cross-validation training folds. The holdout test set is evaluated once.

2. 5-Layer Declarative CASH Space

Both SEVA and black-box baselines navigate the identical configuration space across numerical scaling, categorical encoding, polynomial/ratio engineering, class rebalancing, and regularized boosting.

3. Scientific Traceability

Every trial records the quantified diagnosis, hypothesis, expected outcome, applied mutation, and observed confirmation status in an auditable Lab Notebook.

4. Deterministic Replay

Any evaluated pipeline can be re-executed from its serialized configuration and random seed with zero variance.

CLI Quickstart

# Install SEVA git clone https://github.com/LirielC/SEVA.git cd SEVA pip install -e . # Run single autonomous experiment seva run-agent --dataset credit-g --budget 12 --mode heuristic # Run 4-way comparative ablation benchmark seva run-benchmark --budget 12 --seeds 42 101 202 # Deterministically replay any winning pipeline seva replay --config artifacts/runs/credit-g__seva_heuristic_agent__seed42.json --dataset credit-g --seed 42
